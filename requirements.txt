# AI providers
# Majors, and the caps are the load-bearing part: both SDKs ship breaking
# changes on a major, so the ceiling stays one major above the floor and moves
# deliberately. The floors are the versions this tree is tested against, not
# the oldest that might work — a self-hosted install should not silently
# resolve to an SDK nobody here has run.
#
# Verified against the three call sites in backend/core/ai_provider.py:
# `AsyncAnthropic(api_key=)` + `messages.stream(model, max_tokens, system,
# messages)`, and `AsyncOpenAI(api_key, timeout, base_url, default_headers)` +
# `chat.completions.create(model, messages, stream, max_tokens |
# max_completion_tokens)`. All present in anthropic 1.2.0 / openai 3.6.0.
#
# Both also need httpx >=0.28 (older SDKs passed a `proxies` kwarg httpx 0.28
# removed); neonize requires httpx >=0.28.1 transitively, so httpx cannot be
# pinned down anyway.
anthropic>=1.2.0,<2.0
openai>=3.6.0,<4.0

# Download — yt-dlp + curl-cffi for browser TLS impersonation.
#
# yt-dlp floor: versions below 2026.7 miss current extractor fixes AND —
# the sharp edge — an OLD Python's pip resolves an unbounded "yt-dlp" to
# an ancient release (macOS system python3 is 3.9, for which "latest" is
# a 2025.10 build that can't use curl-cffi ≥0.10 and fails on modern
# YouTube). The floor makes such an install fail loudly instead of
# producing a silently-broken downloader. Upgrade freely above it.
#
# curl-cffi: floor >=0.15 — DO NOT relax it. 0.14's streaming path submits
# `perform` to an internal executor and resets the same libcurl easy handle
# from a done-callback while the calling thread is still parsing the
# response; two threads on one handle SIGABRT the whole backend process — no
# traceback, no failing test, process gone. TikTok's extractor forces
# impersonate=True, so it runs on every TikTok probe and download. Measured
# upstream: 0.14.0 aborted 4 of 6 concurrent-probe runs, 0.15.0 aborted 0 of
# 14. The old <0.15 cap was for yt-dlp <= 2026.04, whose request-handler API
# 0.15 broke; our floor is 2026.7.4, where it is fine.
# Optional at runtime: the service degrades to urllib's fingerprint if it's
# missing/incompatible (see ytdlp_service._IMPERSONATE_TARGET).
yt-dlp>=2026.7.4
curl-cffi>=0.15
